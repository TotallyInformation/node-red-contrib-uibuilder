# Node.js standards

- Files all node.js modules. Nodes, libraries and plugins for Node-RED.

## Coding Standards

- Use Node.js current LTS version but warn if not compatible with v22 LTS.
- Do not use semi-colons unless necessary
- Strings single quotes
- Include proper JSDoc comments, use /** line for short description
- Use trailing commas
- Indent code blocks with 4 spaces
- Prefer arrow functions
- Add TypeScript types/interfaces
