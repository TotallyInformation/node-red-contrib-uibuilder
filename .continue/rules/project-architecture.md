# Project Architecture

This is a combined package of Node-RED/node.js modules and front-end libraries  with:

- Node-RED Nodes and plugins in /nodes
- Runtime libraries used by nodes in /nodes/libs
- Node-RED Editor resources in /resources
- Documentation in /docs
- Front- and back-end source code in /src
- Front-end resources in /front-end
- npm workspaces in /packages
